# 2026-10-02 — Progress Log

## Milestone: Dashboard "Purchases History" live view (branch `feat/purchases-history`)

**Ask:** a Control Center view that shows who purchased keys, live — proposed design first
(list = `sales_history`, detail = merged records), then built on a fresh branch and verified
in a local browser against the real KV data.

### Backend
- `bot_app/services/orders.py`
  - New `get_purchase_history(days, server, search, limit)`: merges BOTH purchase stores —
    `user_purchases_data` (detail: vpn_key / expire_date / disp_gb / price_str) with
    `sales_history` (numeric price, chat_id) — deduped per `order_id` (same rule as
    `get_user_combined_purchase_records`). Points redemptions come through as
    `kind: "points"` and are excluded from revenue sums. Adds `username` / `full_name`
    from profiles, `server_name` via `get_server_display_name` (non-numeric ids like
    "VIP" pass through), ISO `ts` + display `time_str`, newest-first sort.
  - `summary` counters (today/month revenue + count) computed over the server/search
    filter but before the days window; both raw timestamp formats normalize onto `ts`.
- `bot_app/routes_admin.py`
  - `GET /api/admin/purchases` (section 2b): `days` / `server` / `q` / `limit` query
    params, auth via the existing blueprint guard. Live refresh is free — purchase
    writes bump `admin_data_version`, the dashboard SSE channel re-fetches.

### Frontend (`dashboard/`)
- New `src/views/PurchasesView.vue`: 4 summary cards (Today/Month revenue + count),
  day-window chips (24h/7d/30d/All — server-side `days`), server `NSelect` (configured
  servers + "⭐ VIP (Manual)"), debounced search, responsive table (Time / Customer /
  Plan / Server / Amount / Order) that becomes a card list under 720 px via container
  queries, `usePagedList` pagination, row → detail modal (order, customer link to
  `/customers/<id>`, plan, server, amount, time, expires, vpn_key + Copy),
  `loadData({silent})` contract for the App.vue SSE live sync.
- `src/api.ts`: `fetchPurchases()`. `src/router.ts`: `/purchases`. Sidebar nav
  (`AppSidebar.vue`) + mobile bottom nav (`MobileNav.vue`, label "Sales") with
  `CartOutline` icon.
- Naive UI note: `NTabs type="segment"` rendered EMPTY tabs for `NTabPane` children in
  this setup (verified in-browser, empty `.n-tabs-tab` nodes) — replaced with the
  KeysView-style chip-row buttons.
