## 🚀 Overview loading performance fix (same day)

**Symptom**: Overview spun/waited on every visit.
**Root cause**: [admin_telemetry.py](file:///home/zixuan/Projects/outline-key-bot/bot_app/services/admin_telemetry.py) probed each Outline server live on every request — 2 blocking `requests.get` (timeout=4s) per server, run **sequentially**, with **no caching**. 3 unreachable servers ⇒ up to ~24s; frontend axios aborts at 10s.

**Fix**:
- Probe all servers **concurrently** via `ThreadPoolExecutor` (`_probe_all_servers`). Worst case now ≈ one 4s timeout instead of N×.
- **30s TTL cache** for probed server telemetry (`get_servers_telemetry` + `reset_telemetry_cache`), keyed on `(id, api_url)` per server so config edits auto-invalidate. Cheap local KPIs (revenue/keys/customers/slips) stay computed fresh every call.
- `GET /api/admin/overview?refresh=1` bypasses the cache; settings save calls `reset_telemetry_cache()`.
- Frontend: `fetchOverview(force)`; Overview `onMounted` uses cache (instant on revisit), both Sync/refresh buttons force-refresh.

**Verified**: 90/90 backend tests pass; dashboard build passes. Timing demo (3 servers, 2s each): parallel cold 2.00s, cached 2nd call 0.0000s, forced refresh 2.00s (sequential would be 6.00s).

## ⚡ Overview "Failed to load telemetry data" fix — stale-while-revalidate (same day)

**Symptom**: Overview intermittently showed "Failed to load telemetry data" (blank dashboard).
**Root cause**: The 30s TTL cache blocked and re-probed servers synchronously on every expiry. That probe (each server: `/access-keys` + `/metrics/transfer`, sequential) could approach/exceed the frontend's 10s axios timeout when a VPN server was briefly slow → the whole overview failed, wiping even the fast local KPIs.

**Fix (backend [admin_telemetry.py](file:///home/zixuan/Projects/outline-key-bot/bot_app/services/admin_telemetry.py))**:
- **Stale-while-revalidate cache**: fresh → return; stale → return stale instantly + refresh in a single-flight daemon thread; cold/forced → probe synchronously (the only blocking path). After warm-up, user requests never block on the probe.
- Per-request probe timeout 4s → 3s.

**Fix (frontend)**:
- `fetchOverview` overview call now uses a 20s timeout ceiling ([api.ts](file:///home/zixuan/Projects/outline-key-bot/dashboard/src/api.ts)) so a cold probe never trips the default 10s.
- [OverviewView.vue](file:///home/zixuan/Projects/outline-key-bot/dashboard/src/views/OverviewView.vue) `loadData` retries once quietly on a cold failure and never wipes already-loaded data on a failed refresh.

**Verified**: 93/93 backend tests pass (hermetic). Timing demo (2 unreachable servers, 1.5s each): cold 1.50s, warm/stale/after-bg all 0.0000s — the recurring 30s slow spike is eliminated. Dashboard build passes.

- `white-space: nowrap` + ellipsis on `.nav-label`; `overflow: hidden` on the aside.
- Single `ChevronBackOutline` that rotates 180° (`.flipped`) instead of swapping two icons; removed unused `ChevronForwardOutline` import.
- Badge: `NBadge` fades out when collapsed, `.collapsed-badge-dot` fades in (NBadge root is a 0-width div with an absolutely-positioned sup → no layout impact).
