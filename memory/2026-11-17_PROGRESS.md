2. **Fix 2 — Bottom tab bar no longer hides on mere input focus ([`mini_app/src/composables/useMiniApp.ts`](file:///home/zixuan/Projects/outline-key-bot/mini_app/src/composables/useMiniApp.ts) + `style.css`)**
