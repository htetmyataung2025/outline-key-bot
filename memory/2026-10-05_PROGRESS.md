# 2026-10-05 — Progress Log

## Milestone 1: Header POLL badge — amber → green

**Ask (owner):** the header live-sync badge read **POLL** in gold/amber and looked out of
place ("ဝါဝါကြီးကို ကြည့်ရတာ တစ်မျိုးကြီး") — make it green like the rest of the theme.

**Root cause:** since the Option A SSE cut (2026-10-03), production dashboards always run in
`mode-poll`, and `AppHeader.vue` styled that mode with `--warn` amber (bg tint, border, dot,
label) to signal "fallback" — so the badge is permanently gold in prod.

**Fix:** `dashboard/src/components/layout/AppHeader.vue` — removed the three
`.status-pill.mode-poll` amber overrides. The badge now inherits the base green
(`#10b981` accent) styling: green tint background, green border, green pulsing dot, green
label. POLL vs LIVE distinction remains via the label text and the tooltip
("Push unavailable — checking for changes every 30s"). `mode-off` stays gray.

**Verification:** `npm run build` (vue-tsc + vite) clean. CSS-only change — no tests, no
backend files affected.

**Next:** deploy to Vercel to see the green POLL badge in production.
