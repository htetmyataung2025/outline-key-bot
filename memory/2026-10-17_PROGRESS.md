**Goal**: Build a secure, test-driven REST API layer (`/api/user/*`) for the Customer Telegram Mini App (Vue 3 + Vite + Tailwind CSS v4 in `mini_app/`).

### Completed Work:
1. **Security & Authentication Layer**:
   - Updated [`bot_app/helpers/auth.py`](file:///home/zixuan/Projects/outline-key-bot/bot_app/helpers/auth.py):
     - Added `authenticate_user()` and `@require_user_api` decorator.
     - Validates `X-Telegram-Init-Data` header cryptographically using HMAC-SHA256 against `TELEGRAM_TOKEN`.
     - Automatically touches customer profile and registers user ID upon authorized request.
     - Rejects missing or tampered signatures with HTTP 401.

2. **Customer REST API Blueprint**:
   - Created [`bot_app/routes_user.py`](file:///home/zixuan/Projects/outline-key-bot/bot_app/routes_user.py) exposing:
     - `GET /api/user/bootstrap`: Consolidated bootstrap payload for Mini App (user profile, wallet balance, active Outline keys mapped to `VpnKey` model, plans, servers, payment methods).
     - `POST /api/user/claim-daily`: Daily reward points claim with cooldown and streak logic.
     - `POST /api/user/purchase`: 1-Click VPN Plan purchase using wallet balance with automatic fail-safe refund.
     - `POST /api/user/topup-slip`: Payment screenshot receipt upload.
     - `POST /api/user/keys/<path:key_id>/replace`: Key replacement request queue.
     - `GET /api/user/history`: Purchase and slip history.
     - `GET /api/user/leaderboard`: 7-day points leaderboard rankings.
