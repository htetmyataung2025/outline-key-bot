13. **Customer Profile Resolution & Upstash KV URL Fix**:
   - **Root Cause Analysis**:
     - Customer identity was previously missing in the Admin Dashboard because `bot_app/handlers/points.py` and `shop.py` never called `touch_user` on callback interactions, and `.env` contained a markdown link artifact in `KV_REST_API_URL` (`https://relaxed-coral-166624.upstash.io (...)`) that caused Upstash Redis requests to silently fail with `InvalidURL`.
     - In the Mini App, user details (`Zi Xuan`, `@the_zixuan`) appeared because the frontend client reads `window.Telegram.WebApp.initDataUnsafe.user` locally, but the backend store lacked the profile until Mini App bootstrap ran.
   - **Fixes Applied**:
     - **KV_REST_API_URL in [`.env`](file:///home/zixuan/Projects/outline-key-bot/.env)**: Cleaned markdown artifact so Upstash Redis works with `redis_set`/`redis_get` across local dev and production.
     - **Profile Merging & Fallback Resolution in [`bot_app/services/profiles.py`](file:///home/zixuan/Projects/outline-key-bot/bot_app/services/profiles.py)**:
       - `load_all_profiles()` now merges local file state with Redis so existing profiles are never lost.
       - Added `resolve_user_profile(chat_id, fetch_telegram=True)`: When an admin inspects a customer whose name is missing or empty, it automatically queries the Telegram Bot API (`bot.get_chat`) on the fly, persists the resolved `full_name`, `username`, `first_seen`, and `last_seen`, and returns the complete profile.
       - Updated `get_customer_detail` in [`bot_app/routes_admin.py`](file:///home/zixuan/Projects/outline-key-bot/bot_app/routes_admin.py) to use `resolve_user_profile`.
     - **Bot Callback Handlers**: Added `touch_user(getattr(call, "from_user", None))` across all callbacks in [`bot_app/handlers/points.py`](file:///home/zixuan/Projects/outline-key-bot/bot_app/handlers/points.py) and [`bot_app/handlers/shop.py`](file:///home/zixuan/Projects/outline-key-bot/bot_app/handlers/shop.py).
